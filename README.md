# WebNova-Weather-Website
Weather-Website-WebNova is a modern and responsive weather forecasting website built using HTML, CSS, and JavaScript. It provides real-time weather updates, temperature, humidity, wind speed, and weather conditions with a clean UI, smooth animations, and mobile-friendly design.


---

```bash
cd weather-website-webnova
```

---

## 3️⃣ Run Website

Simply open:

```txt

```

inside your browser 🚀
